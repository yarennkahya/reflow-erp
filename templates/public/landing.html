{# ─── FAQ ───────────────────────────────────────────────────────────────────── #}
{% translate "SSS" %}

{% translate "Sık sorulanlar" %}

{% translate "Hangi sektörler için uygundur?" %}

{% blocktranslate %}Temel tasarım üretim yapan her işletmeye uyarlanabilir: gıda, tekstil, elektronik, kimya, imalat. Demo verisi bir kahve kavurma işletmesine aittir; iş akışları ve veri modeli sektörden bağımsız biçimde kurgulanmıştır.{% endblocktranslate %}

{% translate "Stok neden doğrudan güncellenmiyor?" %}

{% blocktranslate %}Her değişiklik bir stok hareketi (ledger) kaydı olarak eklenir. Böylece bakiye her zaman hareketlerin toplamıdır, geçmiş geriye dönük asla bozulmaz ve tam denetim izi mevcuttur.{% endblocktranslate %}

{% translate "Rol bazlı erişim nasıl çalışıyor?" %}

{% blocktranslate %}Her modül Django grup izinlerine bağlıdır. Yetkisi olmayan kullanıcı modülü kilitli görür ve doğrudan URL ile de erişemez. Demo ortamında farklı rol hesaplarıyla bunu test edebilirsiniz.{% endblocktranslate %}

{% translate "AI katmanı veritabanına yazabilir mi?" %}

{% blocktranslate %}Hayır. Model yalnızca tanımlı fonksiyonları çağırabilir; yazma işlemleri her zaman uygulamanın kendi servis katmanından geçer. Böylece AI hiçbir zaman doğrudan veri değiştiremez.{% endblocktranslate %}

{% translate "Teknoloji yığını nedir?" %}

{% blocktranslate %}Backend Django 5.1, veritabanı PostgreSQL (pgvector ile), önbellek ve kuyruk Redis + Celery, konteynerleştirme Docker, web sunucusu NGINX + Gunicorn, AI için OpenAI API.{% endblocktranslate %}
